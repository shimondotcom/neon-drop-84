# NEON DROP

A retro 80s arcade falling-block puzzle game set in a glowing light-grid world: light-line blocks and a horizon grid floor. Every cleared line is wiped by a light-racer streaking across the row (multi-line clears criss-cross), and racers cruise the background grid. One self-contained `index.html` with no build step, hosted on GitHub Pages.

A live leaderboard is always on screen (a side panel on big screens, a scrolling ticker on phones), with a "YOU" row that climbs as you score. After a game, a top-10 score asks for your name (up to 8 characters). Scores are saved in your browser.

## Controls

| Key | Action |
| --- | --- |
| ← → | Move |
| ↑ / X | Rotate clockwise |
| Z | Rotate counter-clockwise |
| ↓ | Soft drop |
| Space | Hard drop (slam) |
| C / Shift | Hold piece |
| P / Esc | Pause |
| M | Mute |
| Enter | Start |

## On phones

- **Drag** sideways on the board to move, drag down to soft drop
- **Flick down** to slam, **flick up** to hold
- **Tap** the right half to rotate clockwise, the left half for counter-clockwise
- Or use the thumb buttons: movement on the left, hold / slam / rotate on the right
- Works in portrait and landscape; pauses automatically when you switch apps
- Add it to your home screen for full-screen play

## Run locally

Open `index.html` in a browser.

## Secret

Enter **↑ ↑ ↓ ↓ ← → ← → B A** at any time for **3× points**, with a full-screen unlock to celebrate. Mid-game, the game freezes for the unlock and the rest of that game scores triple; on the title or game-over screen it arms your next game. On a phone, swipe the eight arrows (on the board mid-game, or on the title screen), then tap the left half (B) and the right half (A). Boosted scores are marked ×3 on the leaderboard.
