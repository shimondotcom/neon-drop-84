# NEON DROP '84

A retro 80s arcade falling-block puzzle game: neon blocks, CRT scanlines, a synthwave grid floor and square-wave chiptune sound. One self-contained `index.html` with no build step, hosted on GitHub Pages.

## Controls

| Key | Action |
| --- | --- |
| ← → | Move |
| ↑ / X | Rotate clockwise |
| Z | Rotate counter-clockwise |
| ↓ | Soft drop |
| Space | Hard drop (slam) |
| C / Shift | Hold piece |
| P / Esc | Pause |
| M | Mute |
| Enter | Start |

On phones, on-screen arcade buttons appear automatically.

## Run locally

Open `index.html` in a browser.
